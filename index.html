🔗 Panduan Opsional untuk Google Sheets
💡 Untuk penggunaan biasa, Anda tidak perlu mengisi link apa pun. Sistem sudah siap bekerja langsung dari browser dan menyimpan data di perangkat Anda.
  1. Buka Google Spreadsheet Anda:
    🔗 Klik di sini untuk membuka Spreadsheet
  2. Buka Apps Script: Klik menu Ekstensi → Apps Script
  3. Ganti seluruh kode di editor dengan isi file Code.gs yang sudah dibuat.
    📁 File ada di: c:\Users\LOQ\Documents\Qr kkn\Code.gs
  4. Deploy sebagai Web App:
    Klik Deploy → New Deployment
    • Type: Web App
    • Execute as: Me
    • Who has access: Anyone
    Klik Deploy → Authorize Access → Salin URL Web App
  5. Inisialisasi Sheet: Setelah deploy, buka URL Web App + ?action=init di browser untuk membuat sheet dan mengisi data peserta otomatis.
  6. Tempel URL ke app.js:
    Buka file app.js → temukan baris:
    const GOOGLE_SCRIPT_URL = 'TEMPEL_URL_WEB_APP_DISINI';
    Ganti TEMPEL_URL_WEB_APP_DISINI dengan URL Web App Anda.
  7. Selesai! Refresh halaman ini. Badge di kanan atas akan berubah menjadi 🟢 Terhubung Google Sheets
✅ Jika Anda ingin sinkron ke Google Sheets, fitur itu bisa ditambahkan nanti, tetapi untuk saat ini absensi tetap berjalan normal tanpa link apa pun.
